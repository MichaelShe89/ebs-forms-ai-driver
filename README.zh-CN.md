# 用 AI 驱动 Oracle EBS Forms

> ## ⚠ 面向 IT 团队，仅限测试环境，禁止用于生产
>
> 这是给 **IT / ERP / QA 工程师**用的内部工具，只在**非生产实例**上运行
> —— 开发环境、测试环境、验收环境、沙箱。**不适用于生产系统，也不面向业务用户。**
> 动手前请先读 [SECURITY.md](SECURITY.md)。
>
> 英文版见 [README.md](README.md)。

让 AI 通过 Oracle EBS Forms 的界面做设置和测试，**不抢鼠标键盘**，客制化校验照常触发。

边界写在下面「哪些地方仍然会碰到你的输入」一节，共 4 条，都是已知且有替代路径的。

---

## 三步开始

**① 人工打开并登录 Forms。** 你自己登录，脚本不负责这个，也不要让 AI 去拉起它。

**② 在本目录开 PowerShell，跑体检：**

```powershell
.\setup.ps1 -CheckOnly
```

全绿再往下。有 `[FAIL]` 就按它打印的提示解决——**不要跳过前置条件去硬试**，
那样只会得到误导性的报错，这是目前为止最常见的翻车方式。

**③ 一键落地：**

```powershell
.\setup.ps1
```

它会自动：找 Python / 找 JDK8 / 找 Forms 进程 / 生成口令 / 编译 agent /
附加到 JVM / 握手验证。打印"全部通过"就说明读写通道都通了。

## 给 AI 助手看的

把 **`MANUAL.zh-CN.md`** 整份发给你的 AI 助手，并在手册 §15 填上环境信息和具体任务。

助手拿到后应当：

1. 先跑 `setup.ps1`，不要自己从零手搓 attach 流程；
2. **先读 §14 排查方法** —— 比故障字典更重要。字典是别人踩过的坑，
   §14 是你自己踩新坑时该怎么走。你一定会遇到手册没写的问题，
   能不能自己走出来取决于 §14；
3. 再通读 **§7 故障字典（38 条）** 和 **§8 死路清单（12 条）**；
4. 遇到问题**先查字典**，不要自己写探针程序去试探沙箱边界。

> **最重要的一条：不要另起炉灶写最小 agent 去探测。**
> 已经有两个 AI 因此得出"沙箱级限制、方案不可行"的错误结论，
> 而真实原因只是包名重复用了（R2）或 jar 放错目录（R5）——
> 这套机制在带 `AWTAppletSecurityManager` 的 JVM 上被反复验证通过。

## 已知的坑（详见手册）

| 现象 | 别被骗 |
|---|---|
| `Agent JAR not found or no Agent-Class attribute` | 通用包装，真实原因通常是**包名重复**或**jar 目录不对**，不是 jar 坏了 |
| `python` 没反应或弹商店 | PATH 上是 Windows Store 的 0 字节占位符，不是没装 Python |
| `new File` 成功但 `new JarFile` 失败 | `new File` 从不做权限检查，成功说明不了任何事 |
| 并发请求提示"成功"但数据没变 | 界面提示不可信，一律查库确认 |

## 哪些地方仍然会碰到你的输入

「不抢鼠标键盘」对 agent 通道是成立的。边界在哪里，说清楚比含糊过去有用：

| 位置 | 会碰到什么 |
|---|---|
| `driver/drive.py` —— 填字段、点击、按键、切页签 | **什么都不碰。** 事件在 JVM 内部派发，根本不进操作系统输入队列 |
| MCP 写工具 —— 菜单、按钮、LOV | **什么都不碰。** 和 Forms UI 线程共享输入队列，但不调 `SetFocus` |
| `forms_key` | **会抢键盘。** 功能键必须是真按键。改用菜单路径或 `drive.py`，工具自己也这么提示 |
| 每个 session 第一次调用，且 Forms 是最小化的 | **闪一下。** Windows 不给图标化窗口 active 状态，只能先还原再把前台还回去 —— 每 session 一次，不是每个动作一次 |
| `forms_type(method="paste")` | **覆盖你的剪贴板。** 不抢焦点。`drive.py` 完全不用剪贴板 |

另外 Forms 窗口必须留在屏幕上（不能最小化，要在当前显示的桌面上）。
它不会抢你的焦点，但它也不是隐形的。

## 安全须知

- agent 端口只绑 `127.0.0.1` 且带口令。**不要**改成绑 `0.0.0.0`。
- `secret.txt` 用完删掉，不要提交代码库，不要放进要外发的压缩包。
- 数据库账号只给 `SELECT`。
- agent 随 Forms 关闭自动消失，不要做成常驻服务。
- **只在测试环境使用**，生产环境需要单独评估与签字。

> **本方案包不含任何特定企业的环境、配置或业务数据。**
> 文中所有示例值都是占位符，需要换成你们自己实例的实际值 ——
> 手册里每一处都写了用什么 SQL 查出来。
>
> 建议按 §14.10 的做法，逐步积累一份属于你们自己的流程与客制化关卡记录。
> 这套东西真正省下来的时间，会随那份记录一起增长。
